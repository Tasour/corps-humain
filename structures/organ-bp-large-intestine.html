Limites du modèle

Structure assemblée à partir de 8 pièces BodyParts3D. Présente uniquement dans BodyParts3D. Modèle pédagogique : ne pas utiliser pour un diagnostic.

Points d'intérêt

  1. La récupération d'eau — Le côlon absorbe l'eau et les électrolytes qui restent dans les résidus alimentaires, ce qui compacte les selles.
  2. Le transit lent — Le côlon transverse traverse l'abdomen d'un côté à l'autre ; le transit y dure plusieurs heures, sous l'action du microbiote.
  3. Le stockage final — Le rectum stocke les selles avant l'exonération ; sa distension déclenche le besoin d'aller aux toilettes.
