## Regle de decision

1. Licence explicite CC0/CC BY sur la page du asset → autorise.
2. Licence propre ou restrictive → refuse, meme si le telechargement est gratuit.
3. Pas de page de licence → refuse.
4. Toujours conserver une copie de la page de licence dans le dossier de provenance.
