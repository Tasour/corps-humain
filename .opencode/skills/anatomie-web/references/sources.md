## Attribution FMA

Le depot `uw-sig/FMA` est sous CC BY 4.0. La FAQ UW rappelle que la **Release Version** peut
etre distribuee gratuitement avec attribution, mais que le nom « Foundational Model of
Anatomy » et les marques de l'Universite de Washington ne peuvent pas etre utilises pour
une derivee. Dans CORPS, on cite uniquement les **FMAID** et on ne redistribue pas `fma.owl`.

## Regles de citation

- Format : `FMA12345 — Shared anatomy name, source URL, license, accessed 2026-11-20`.
- Conserver un extrait court (1 phrase) pour prouver que la source dit bien ce qu'on avance.
- Deux sources independantes obligatoires pour un verdict `confirme`.
- Un resultat de recherche seul ne suffit pas : toujours ouvrir la page source avec webfetch.
