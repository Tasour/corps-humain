# Vague 1 — agrégats exclus du manifeste

**Date : 20 novembre 2026 · Statut : terminée, après vérification visuelle.**

## Méthode

5 agents en worktrees Git isolées, une par famille (dents, côtes, vertèbres, mains/pieds,
crâne/nez). Chacun a vérifié dans le manifeste et l'inventaire que des **structures
individuelles de remplacement** existaient, puis produit un patch de données
(`docs/inventaire-anatomique/patches/*.json`). Les 5 commits ont été fusionnés par
cherry-pick dans le dépôt principal, puis appliqués au jeu de données.

Les sources BodyParts3D n'étant plus présentes sur le disque au moment de l'application,
`scripts/appliquer-exclusions-revue.mjs` a filtré le **manifeste** sans reconstruire les
chunks : les octets des structures exclues restent dans les fichiers binaires (espace perdu,
sans effet visuel). Le pipeline `build-anatomy-v2.mjs` applique les mêmes patchs lors d'un
rebuild normal, donc un futur rebuild retrouvera le même résultat sans octets morts.
