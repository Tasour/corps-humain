# Chasse aux organes — premier jeu natif v2

Date : 19 novembre 2026 · Page : `/v2.html` · Preuve : `npm run test:chasse` → **7/7**,
`npm run test:v2` → **35/35**. Captures : `docs/analyses/chasse/`.

## 1. Pourquoi ce chantier

Le chantier 7 (fusion v1 + v2) demande de retrouver dans l'atlas complet les
fonctionnalités de la v1 sans perdre les pathologies, les jeux et la coupe. La v1
s'appuie sur 47 entités nommées et un modèle de picking différent ; la v2 expose
2 039 structures TA2. Plutôt que de recopier le jeu de la v1, la « Chasse aux
organes » a été réécrite contre le moteur v2 : la cible est une structure réelle
du manifeste et le clic passe par le picking exact.

## 2. Règles

- 27 cibles réparties sur trois couches : organes (22), os (4), muscle (1).
- Une seule couche est visible à la fois : le joueur cherche la structure, pas
  un système noyé sous les autres. La peau reste masquée.
- Bonne réponse : 10 points + 3 par réponse consécutive. Mauvaise réponse ou clic
  dans le vide : −2 secondes. Partie de 90 secondes.
- La fiche latérale affiche la cible, l'indice anatomique, le score, le temps
  restant et la barre de progression.

## 3. Contrôles mesurés

`tests/chasse.test.mjs` (hors navigateur) :

1. les 27 identifiants existent dans `public/models/v2/manifest.json` ;
2. au moins 20 cibles ;
3. identifiants uniques ;
4. libellés et indices renseignés ;
5. libellés uniques ;
6. les trois catégories (organe, os, muscle) sont représentées ;
7. chaque cible organe possède une géométrie non vide.

`tests/v2-tests.mjs` (bout en bout) :

- démarrage par le bouton réel, HUD visible, compteur de performance masqué ;
- cible osseuse `bone:tibia-l` forcée, caméra cadrée sur son centre, **clic réel**
  au centre du canvas → score 10, `found = 1`, retour « Exact » ;
- mauvaise structure → temps −2 s, série remise à zéro, score inchangé ;
- fermeture → HUD masqué, couche « Organes » restaurée, os et muscles désactivés,
  fiche revenue à l'état neutre.

## 4. Défaut moteur corrigé au passage

En testant le clic sur le tibia, le picking renvoyait « Fascia crural » alors que
la couche muscle était masquée. Cause : `setCategoryVisible()` masquait le mesh
fusionné principal mais pas le mesh des séreuses/fascia (`<catégorie>:membrane`),
resté visible et cliquable. La correction masque les deux meshes ensemble ; un
contrôle dédié vérifie désormais, pour chaque couche, que le mesh principal **et**
sa membrane sont invisibles quand la couche est désactivée.

## 5. Limites

- Le jeu ne couvre que 27 structures ; les autres restent explorables dans l'atlas.
- Pas de classement persistant ni de difficulté progressive.
- Les pathologies simulées, le jeu de diagnostic et la coupe anatomique restent
  dans la version classique (`/index.html`), accessible par le lien de la fiche.
