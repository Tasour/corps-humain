# Guide d'utilisation Blender — corps animés

Ouvrir `docs/humain-femme-complet.blend` ou `docs/humain-homme-complet.blend`.

- Armature `Corps Rig` : 62 os, 6 pistes NLA (salsa, marche, étirement, tourbillon, course, équilibre).
- Une seule piste active à la fois : dans l'éditeur NLA, dé-muter la piste voulue et muter les autres.
- Caméres : face (active), dos, profil, trois-quarts.
- Couches : peau visible par défaut ; les autres systèmes sont masqués mais présents.
- Scripts reproductibles dans `scripts/` (voir `docs/ANIMATION-COMPLETE.md`).
